Pipeline Medallion para datos de generación eléctrica EERSA

Microsoft Fabric, PySpark, Delta Lake, Python, pandas, OneLake, Medallion Architecture, Kimball

GitHub

Descripción del Proyecto

Pipeline de ingeniería de datos end-to-end que procesa registros diarios de generación eléctrica de EERSA (Empresa Eléctrica Riobamba) implementando arquitectura Medallion Bronze/Silver/Gold sobre Microsoft Fabric. Ingesta 12 archivos Excel mensuales con datos de plantas hidroeléctricas (Alao, Río Blanco, Nizag) y Sistema Nacional Interconectado, aplicando limpieza, deduplicación, quality gates con tabla de cuarentena, clasificación de fuentes y modelado dimensional Kimball. Genera 4 tablas Gold listas para BI: dimensión de plantas, hechos diarios pivoteados, agregados mensuales con factor de carga, y balance energético mensual distinguiendo generación propia vs interconexión. Procesó 7,695 filas Bronze, conformó 5,840 filas Silver y produjo KPIs mensuales para los 12 meses de 2021, con linaje completo en cada capa.
