Computer Vision Engineer (Contractor) - BIM Automation

8base

octubre 2025 - Actualidad

Descripción del Puesto

Contratado como especialista en Computer Vision para desarrollar un sistema de reconocimiento automático de planos arquitectónicos y generación de modelos BIM en formato IFC. Proyecto independiente enfocado en automatización del proceso de conversión de documentación 2D a modelos tridimensionales estructurados.

Alcance del proyecto:
- Diseño e implementación de pipeline completo de Computer Vision para detección y clasificación de elementos arquitectónicos (muros, puertas, ventanas, columnas)
- Desarrollo de algoritmos de extracción de geometría y relaciones espaciales desde planos 2D
- Generación automática de archivos IFC (Industry Foundation Classes) siguiendo estándares OpenBIM
- Procesamiento de documentación técnica de construcción mediante técnicas de ML/Deep Learning
- Integración end-to-end desde input (planos PDF/DWG) hasta output (modelos IFC validados)

Entregables: Sistema funcional de reconocimiento automático, pipeline de procesamiento escalable, documentación técnica.
