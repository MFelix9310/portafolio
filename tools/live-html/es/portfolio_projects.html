Data Scientist Data Analyst Python Developer
Detalles GitHub

Pipeline de datos con arquitectura Medallion (Bronze, Silver, Gold) para estimar la probabilidad de falla y el indice de confiabilidad de elementos estructurales de acero mediante simulacion Monte Carlo. Pipeline Medallion para datos de generación eléctrica EERSA

Microsoft Fabric, PySpark, Delta Lake, Python, pandas, OneLake, Medallion Architecture, Kimball

Data Scientist Data Analyst Python Developer
Detalles GitHub

Pipeline de ingeniería de datos end-to-end que procesa registros diarios de generación eléctrica de EERSA (Empresa Eléctrica Riobamba) implementando arquitectura Medallion Bronze/Silver/Gold sobre Microsoft Fabric. Ingesta 12 archivos Excel mensuales con datos de plantas hidroeléctricas (Alao, Río Blanco, Nizag) y Sistema Nacional Interconectado, aplicando limpieza, deduplicación, quality gates con tabla de cuarentena, clasificación de fuentes y modelado dimensional Kimball. Digital Twin con ML para Monitoreo Sísmico de Edificios

Random Forest, Neural Networks, Physics-Informed ML, Scikit-learn, Digital Twin, Seismic Analysis, Real-Time Monitoring, Structural Health Monitoring, Python

Data Scientist Data Analyst Python Developer
Detalles Demo

Sistema de gemelo digital impulsado por machine learning para monitoreo en tiempo real de salud estructural de edificios durante eventos sísmicos. Integra tres módulos: (A) predicción de patrones de deformación estructural mediante redes neuronales entrenadas con datos de movimiento del suelo, (B) análisis predictivo de comportamiento no lineal con datos experimentales validados mediante física informada, y (C) clasificación de estado de daño utilizando Random Forest con 94.8% de precisión. Predicción de Campos de Esfuerzos con Graph Neural Networks

Graph Neural Networks, PyTorch, FEM, Matplotlib, NumPy, Deep Learning, Structural Mechanics, Python

Data Scientist Data Analyst Python Developer
Detalles Demo

Sistema de machine learning que predice campos de esfuerzos estructurales 150 veces más rápido que análisis FEM tradicional. Implementa Graph Neural Networks (GNNs) para convertir mallas de elementos finitos en grafos, donde cada nodo representa un punto de la estructura y la red aprende las relaciones físicas entre ellos. El modelo entrenado con ~300 configuraciones de vigas logra predicción de esfuerzos von Mises en 0.18 segundos vs 28 segundos de FEM convencional, manteniendo 98% de precisión. Aplicable en fases exploratorias de diseño, optimización paramétrica con 100+ variantes, y análisis de sensibilidad donde se requiere rapidez sobre precisión milimétrica. Basado en investigación de Maurizi et al. (2022) publicada en Nature Scientific Reports. La visualización muestra deformación de viga cantiléver bajo carga con mapa de calor del campo de esfuerzos evolucionando en tiempo real.

Digital Twin Sísmico en Tiempo Real con Machine Learning

Python, NumPy, Matplotlib, Seaborn, SciPy, Scikit-learn

Data Scientist Data Analyst Python Developer
Detalles Demo

Desarrollé desde cero una simulación de Digital Twin sísmico en Python que predice el daño estructural de un edificio mientras un terremoto ocurre. El proyecto consta de dos paneles animados sincronizados: el primero reproduce un acelerograma sintético generado con el modelo Kanai-Tajimi + Clough-Penzien calibrado a condiciones de suelo ecuatorianas (Tipo D, NEC-15), y el segundo muestra la predicción de un modelo LSTM que estima el inter-story drift ratio de un marco de concreto reforzado de 5 pisos en tiempo real.
