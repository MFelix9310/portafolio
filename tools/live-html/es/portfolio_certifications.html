PCEP – Certified Entry-Level Python Programmer

OpenEDG Python Institute

agosto 2024
Ver Certificado Verificar Credencial

El PCEP (Certified Entry-Level Python Programmer) es una certificación básica de programación en Python ofrecida por el Python Institute de OpenEDG. Esta certificación está diseñada para principiantes que desean validar sus habilidades fundamentales en Python y es el primer paso en la ruta de certificaciones profesionales de Python. El PCEP verifica que el candidato tiene un conocimiento general de los conceptos de programación en Python, entiende la sintaxis y la semántica del lenguaje, y es capaz de resolver problemas básicos utilizando Python. La certificación demuestra que el programador puede trabajar con las características esenciales del lenguaje y realizar tareas de codificación simples de manera independiente. Esta certificación es ideal para estudiantes, personas que están cambiando de carrera, o profesionales que buscan complementar sus habilidades técnicas con conocimientos de programación en Python.

Expira: 21/08/2028

Python Essentials 1

Cisco

agosto 2024
Verificar Credencial

Este curso introductorio de Cisco Networking Academy proporciona una base sólida en programación con Python. Diseñado para principiantes, cubre conceptos fundamentales como variables, tipos de datos, operadores, estructuras de control (condicionales y bucles), funciones, y fundamentos de programación orientada a objetos. Los estudiantes aprenden a escribir código limpio y eficiente, resolviendo problemas prácticos mediante laboratorios interactivos. Al completar el curso, los participantes pueden obtener la certificación PCEP (Python Certified Entry-level Programmer), un reconocimiento oficial de la Python Institute que valida las habilidades básicas de programación en Python.

Expira: 09/08/2028
