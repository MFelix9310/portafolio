Predictor de Curvas Esfuerzo-Deformación para Materiales Compuestos

Python, Streamlit, Scikit-learn, NumPy, Pandas, Matplotlib, Joblib, SciPy

Ver Demo

Descripción del Proyecto

Desarrollé una aplicación web interactiva que predice el comportamiento mecánico de materiales con diferentes porcentajes de relave mediante modelos de machine learning. La herramienta permite ajustar parámetros como tiempo de curado y composición, generando visualizaciones en tiempo real que optimizan el diseño de materiales y reducen la necesidad de costosos ensayos físicos.
