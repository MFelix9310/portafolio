Structural Stress Field Prediction with Graph Neural Networks

Structural Stress Field Prediction with Graph Neural Networks

Data Scientist Data Analyst Python Developer
Details Demo

Machine learning system that predicts structural stress fields 150x faster than traditional FEM analysis. Implements Graph Neural Networks (GNNs) to convert finite element meshes into graphs, where each node represents a structural point and the network learns physical relationships between them. Model trained on ~300 beam configurations achieves von Mises stress prediction in 0.18 seconds vs 28 seconds for conventional FEM, maintaining 98% accuracy. Applicable in exploratory design phases, parametric optimization with 100+ variants, and sensitivity analysis where speed is prioritized over millimeter precision. Based on Maurizi et al. (2022) research published in Nature Scientific Reports. Visualization shows cantilever beam deformation under load with real-time evolving stress field heat map.

Real-Time Seismic Digital Twin with Machine Learning

Python, NumPy, Matplotlib, Seaborn, SciPy, Scikit-learn

Data Scientist Data Analyst Python Developer
Details Demo

Built from scratch a seismic Digital Twin simulation in Python that predicts structural damage while an earthquake is happening. The project features two synchronized animated panels: the first displays a synthetic accelerogram generated with the Kanai-Tajimi + Clough-Penzien model calibrated to Ecuadorian soil conditions (Type D, NEC-15), and the second shows an LSTM model predicting the inter-story drift ratio of a 5-story RC frame in real time.
