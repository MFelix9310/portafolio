University Laboratory Registration System

Django 4.2, Python 3.10, SQLite/MySQL, HTML5, CSS3, JavaScript, Bootstrap 5, AJAX, ReportLab, openpyxl, PythonAnywhere

GitHub

Project Description

Complete web application built with Django for real-time control and monitoring of university laboratory access. Features dual registration modes (first-time and quick), automatic validations, admin panel, real-time monitoring with AJAX, and PDF/Excel report generation. Handles Ecuador timezone, prevents duplicate registrations, and automatically updates expired statuses.
