Computer Vision Engineer (Contractor) - BIM Automation

8base

October 2025 - Present

Job Description

Contracted as Computer Vision specialist to develop an automated architectural plan recognition system and BIM model generation in IFC format. Independent project focused on automating the conversion process from 2D documentation to structured three-dimensional models.

Project Scope:
- Design and implementation of complete Computer Vision pipeline for detection and classification of architectural elements (walls, doors, windows, columns)
- Development of algorithms for geometry extraction and spatial relationships from 2D plans
- Automatic generation of IFC (Industry Foundation Classes) files following OpenBIM standards
- Processing of construction technical documentation using ML/Deep Learning techniques
- End-to-end integration from input (PDF/DWG plans) to output (validated IFC models)

Deliverables: Functional automatic recognition system, scalable processing pipeline, technical documentation.

Tech Stack: Python, Computer Vision, Deep Learning, IFC, IfcOpenShell, Object Detection, Image Processing.
