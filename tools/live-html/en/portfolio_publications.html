Programming with MATLAB

Pazmiño A., Alexandra O. Jácome T., Jairo R. Ruiz M., Félix A.

Publicaciones CIDE

2023
Link PDF

In today's world, programming knowledge is vitally important for students and professionals. To read this book, it is necessary to understand the basic functioning of MATLAB software, which is used to study different programming structures. The first chapter provides a quick review of MATLAB, covering basic operating principles and how to input and manage vectors and matrices in the software. The second chapter introduces programming with solved exercises focusing on sequential structures, control structures, and their different types such as simple, nested, compound, and multiple branching. The chapter also covers repetition structures with solved exercises using for and while loops. To reinforce learning, a number of practice exercises are provided at the end of the chapter. The third chapter addresses the management of vectors and matrices using control and repetition structures, enabling readers to effectively handle stored information by accessing each position within these structured variables. The fourth and final chapter deals with user-defined functions. As MATLAB is modular software, exercises are solved using knowledge from previous chapters, creating different types of functions including single-input/single-output functions, multi-input/single-output functions, and multi-input/multi-output functions. This modular approach allows readers to create programs that are easier to read and provides solutions to proposed exercises. Each chapter includes exercises for readers to solve, allowing them to practice what they've learned and reinforce their knowledge.
