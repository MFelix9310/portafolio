Data Engineering Pipeline — 250M Job Postings Clustering & O*NET Gap Analysis

Python, BGE-large-en-v1.5, UMAP, HDBSCAN, IncrementalPCA, DuckDB, PyArrow, sentence-transformers, BERTopic, DigitalOcean Spaces, rclone FUSE, RAPIDS cuML, Parquet

GitHub

Project Description

End-to-end data engineering pipeline processing 250M US job postings (2007–2025). Streams 953GB of BGE-large embeddings from cloud storage via FUSE mount with zero local download. Applies IncrementalPCA (1024→50D), UMAP (50→5D), and HDBSCAN to auto-discover 208 occupational clusters — outperforming K-Means baseline (DBCV=0.240 vs Silhouette=−0.010). c-TF-IDF labels each cluster, SOC purity analysis flags 17 emerging occupations and 14 taxonomy misalignments, and gap scores quantify divergence between real job postings and official O*NET descriptions. Built to support a PhD dissertation at Stevens Institute of Technology.
